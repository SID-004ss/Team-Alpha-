# Team Alpha - Team Management System

## Description
This is a full stack web application built using MERN stack to manage team members.

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB

## Features
- Add Member
- View Members
- View Member Details

## API Endpoints

### GET /api/members
Fetch all members

### GET /api/members/:id
Fetch single member details

### POST /api/members
Add a new member

## How to Run

1. Clone the repository
2. Go to backend:
   cd backend
   npm install
   npm run dev

3. Go to frontend:
   cd frontend
   npm install
   npm start
